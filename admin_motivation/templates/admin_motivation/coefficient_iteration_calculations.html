Планы и параметры

Общий справочник исключений подразделений применяется ко всем годам, плану и факту. У политиков дополнительно исключены канал ДПП и группа планов HEAT. {% if request.user.is_superuser %}Справочник исключений{% endif %}

План и факт всех ключей с одинаковым SubdivisionName объединяются; ставки и директора выбираются для этого общего подразделения. В 2026–2027 Москва и Термотрейд объединены, используются московские ставки. В 2025 они считаются отдельно; для ТТ используются ставки Москвы. Получатели директорских ставок за 2025 берутся из исторической колонки сопоставления.

Для 2027 показан общий план политиков, без распределения между сотрудниками. Для 2025 план политиков распределяется по факту авторов, HEAT исключён только у политиков. Годовая часть 2026 берётся только из IV квартала; в 2027 — из всех четырёх кварталов.
