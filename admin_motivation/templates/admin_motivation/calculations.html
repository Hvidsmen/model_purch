Как выполняется расчёт и что нужно для подключения

Задания выполняет SQL Server Agent, в том числе после перезапуска портала. Одновременные запуски из портала блокируются.

Процедура motivation.sp_CalcBySub запускается через подготовленную копию motivation.PortalCalcBySub, которая учитывает объединённые подразделения. Исходная процедура сохраняется.

Подключение: DWH_SQL_CONN_STR. Нужны работающая служба SQL Server Agent, права на задания msdb, чтение определения исходной процедуры и создание объектов в схеме motivation.
