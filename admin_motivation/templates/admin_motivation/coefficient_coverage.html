Покрытие коэффициентами

Проверка точного ключа в настройках портала: подразделение, дата действия, группа планов продаж, группа ERP, бренд, вид работника и ступень K0–K4. Значения коэффициентов эта проверка не меняет.

Для утверждённой версии проверяется действующая утверждённая цепочка. Неутверждённая версия рассматривается как проект с её даты начала действия. План проверяется по загруженной классификации. Факт — по ключам соединения с коэффициентами (не по названию отдельной модели). Пустой бренд в ключе показан как «пусто». Директора проверяются по текущим привязкам и сохранённым настройкам. Объём повторяется по типам работников; его нельзя суммировать между типами.
