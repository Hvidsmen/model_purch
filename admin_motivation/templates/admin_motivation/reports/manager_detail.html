Расширенная таблица мотивации · {{ data.currency }}

План и отгрузки — USD. Мотивация — {{ data.currency }}. В блоке «Итого» план, факт и процент выполнения берутся из строк «Год». Мотивация и доплата суммируются по всем периодам. При отсутствии полных годовых данных факт периода в «Итого» — сумма физических отгрузок выбранных кварталов; план и процент остаются неопределёнными. Накопительные окна выполнения не складываются. Коэффициенты K0–K4 на каждом уровне взвешены по отгрузкам соответствующих сегментов O0–O4.

{% if data.global_subdivision_mode %}Для «Подразделение(Глобально)» план и процент выполнения периода не задаются; факт периода — собственные отгрузки. Для строк со смешанными формулами показатели выполнения мотивации не объединяются.{% endif %}
