Распределение премий

1. Общий множитель гендиректора → 2. Продажи по людям → 3. Ребаланс политиков → Excel и ссылка финансистам.

Гендиректор подтверждает один общий множитель подразделения за период (по умолчанию 1,0) для политиков, продаж, директоров и кураторов. Он применяется к рассчитанным премиям один раз; план и реальные продажи сохраняются. Здесь фиксируется снимок рассчитанных фондов: последующий пересчёт их не изменяет. По одному распределению на подразделение и период, в выбранной валюте.
