Отметьте товары в первом столбце. Умножаются текущие значения в таблице, включая несохранённые правки. Сохранение — отдельной кнопкой после проверки.

1,1 — увеличить на 10%; 0,9 — уменьшить на 10%; 0 — обнулить. Множитель неотрицательный. Премия при этом может измениться; для сохранения бюджета используйте «Балансировка премии». Для директора подразделения меняются только ставки выбранного сотрудника.
