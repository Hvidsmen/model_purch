Правила балансировки

База — строки загруженного плана с даты начала выбранной версии. В глобальном режиме используются глобальные ставки; в режиме подразделений — локальные. Режим «Компания» для локальных коэффициентов открывает все подразделения. Глобальные ставки директоров учитываются отдельно для каждого директора, представленного в коэффициентах подразделений.

Ручные значения фиксируются. Выбранные для компенсации ненулевые коэффициенты умножаются на общий множитель в пределах сохраняемого бюджета: вклад в компенсацию пропорционален их исходной плановой премии. Остальные значения сохраняются. Нулевые коэффициенты пропорционально не увеличиваются. При недостаточном выборе, выходе за границы −100%…100% или невозможности сохранить сумму до цента расчёт выдаёт объяснение.

Минимальные коэффициенты при отсутствии точного совпадения пересчитываются заново. Коэффициенты руководителя, формулы выполнения и порог выплаты не редактируются этой формой. Здесь балансируется плановая премия по суммам сегментов плана, как в сравнении планов; фактическая выплата зависит от выполнения плана и поправок. Последнюю утверждённую версию можно сохранить в новый черновик с той же датой начала действия. Исторические версии доступны для анализа.

Выберите план и загрузите исходные значения.

«Ручное» — задайте новый процент. «Авто» — разрешите автоматическую компенсацию. «Не менять» — сохраните исходное значение. Массовый выбор действует на все строки с текущими фильтрами, включая другие страницы.
