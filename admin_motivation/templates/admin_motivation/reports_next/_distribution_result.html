После распределения

Завершённое распределение директора по сотруднику и периоду, для подразделения, года и валюты; зафиксированный результат сохраняется при последующих пересчётах. Суммы не разбиваются по товарам. При товарном отборе итог распределения не показывается. «Не распределено» — завершённой версии для этого отбора нет.
