# Оформление мотивации по подразделениям

`subdivision_motivation_styled.rdl` использует оформление отчёта менеджера:
Segoe UI, тёмно-синий центрированный основной заголовок, светлые шапки
#F1F5F9, акценты итогов #E8EFF8, фон числовых итогов #F7F9FC,
тонкие границы #DCE3EC. Обработаны также пустые ячейки.

Условный белый текст показателей заменён на тёмно-синий для читаемости
на светлом фоне. Условия и красная индикация сохранены.

XML разбирается. После удаления Style и DefaultFontFamily исходное
и итоговое дерево совпадают: SQL, формулы значений, параметры, размеры,
группы и раскрытие не изменены. Внешний вид требует Preview Report Builder.
