# Оформление отчёта «Факт закрытых сделок»

Подготовлен `closed_deals_redesigned.rdl` в стиле отчёта мотивации менеджера:
Segoe UI, синий заголовок, светлые серо-синие шапки таблиц,
выделенные итоги и тонкие границы. Сохранено чередование фона строк.

XML проверен. После удаления элементов Style и DefaultFontFamily
исходное и итоговое дерево совпадают. SQL, формулы, параметры, источники,
группировки, размеры и интерактивное раскрытие не изменены.
Нужна визуальная проверка в Preview Report Builder: сервер SSRS недоступен.

## Точное соответствие оформлению менеджера

В `closed_deals_matching_manager_style.rdl` обработаны также пустые ячейки
итогов: прежняя тёмная заливка полностью удалена. Шапки используют #F1F5F9,
числовые итоги — #F7F9FC, подпись итога — #E8EFF8. Основной заголовок
центрирован, Segoe UI 24 pt без жирного начертания, белый на #1E3A5F.
Проверено совпадение XML вне элементов оформления с предыдущим вариантом.
