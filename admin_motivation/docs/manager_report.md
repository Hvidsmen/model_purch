# Отчёт «Мотивация менеджера»

При смене вида работника или подразделения браузер сбрасывает автора и отправляет форму в режиме «Обновить списки». Предыдущий автор не остаётся выбранным для другого разреза. Список авторов загружается только при заполненных типе и подразделении; остальные выбранные параметры (квартал, группы, валюта) сохраняются. Без JavaScript доступна прежняя кнопка обновления.

Годы в шапке берутся из DISTINCT Год таблицы DataWH.motivation.ReportMotivationByDealAuthor по выбранным типу, филиалу, автору и группе планов, не из текущей даты сервера. Если в данных несколько лет, перечисляются все. Исходная view может не передавать Год, поэтому используется отдельный параметризованный read-only запрос.

Переключатель валюты мотивации: USD (по умолчанию) / RUB. Источник RUB — поля СуммаМотивацииRUR, СуммаМотивацииRURУчетПроцента, ОстатокRUR. В квартальных/годовых выражениях меняются только ссылки на исходные суммы, производные внутренние псевдонимы сохраняются для общего рендеринга. Курс валют не используется. План и отгрузки для выполнения плана и «осталось до 100%» остаются в исходных USD, а не выдаются за рубли. Валюта явно обозначена в заголовке и подписи мотивации.

Для RUB перечисленные поля должны быть доступны в используемой отчётом view DataWH.motivation.vReportMotivationByDealAuthorForAAuthor. Её определение в репозитории отсутствует: live SQL здесь не проверялся и внешний объект автоматически не изменяется.

Подключение reports.js имеет версию в URL, чтобы браузер не использовал старую копию скрипта без зависимых фильтров после обновления портала. Список авторов менеджерского отчёта каждый раз читается из SQL без пятиминутного кэша; NULL/пустые ФИО не попадают в выбор. При действительно пустых данных выводится объяснение вместо молча пустого списка. Проверка lookup выполняется с настоящим SELECT на изолированной SQLite-таблице (без проверки T-SQL на корпоративном сервере), включая появление данных после первоначально пустого результата.
