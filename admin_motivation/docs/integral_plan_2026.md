# Интегральные коэффициенты по плану 2026

В «Отчётах» добавлен отдельный расчёт «Интегральные коэффициенты · План 2026».
Выбираются загруженный план со строками 2026 года и утверждённая версия
коэффициентов подразделений. Выбранный набор ставок применяется ко всему
выбранному плану 2026, независимо от дат отдельных строк. Это бюджетная оценка
полной премии, без порогов фактического выполнения, удержания годовой части
или переходного ограничения IV кварталом.

**Два коэффициента** для каждого подразделения:

- Политики + Продажи = (расчётная премия политиков + премия продаж) / план.
- Директора = сумма расчётных премий действующих привязанных директоров / план.

Результаты показаны как проценты. Для итоговой строки используется сумма премий /
сумма плана; проценты подразделений не усредняются. Знаменатель не умножается
на количество директоров. Расчётные суммы — USD, без валютного пересчёта.

## Источники

Только строки выбранного SalesPlanScenario за 01.01–31.12.2026 с непустым
подразделением; глобальные дубли строк не участвуют. Используется уже загруженный
план и его суммы O0–O4. Этот отчёт не загружает недостающие строки/подразделения
из DWH и не изменяет SQL импорта плана. На странице сохраняются название и
источник плана, дата его загрузки, учтённые месяцы, версия/ревизия коэффициентов
и действующие объединения подразделений. Вентиляция исключается стандартным
правилом мотивации; остальные подразделения берутся из выбранного плана.

Премия товарного сочетания = сумма USD_Oi × Ki. Для политиков HEAT и канал ДПП
не участвуют; для продаж и директоров участвуют. Общий знаменатель — весь план
подразделения. Точные ставки подразделений имеют приоритет. При их отсутствии
используется действующее правило предварительного расчёта плана: минимум
группы, затем минимум таблицы того же вида мотивации. Применение минимума
отмечается в примечании и в Excel. Полностью отсутствующие ставки не заменяются
нулём: соответствующий результат остаётся неопределённым, включая общий итог.

Директора: текущие неархивные сотрудники с действующей привязкой к подразделению.
Коэффициенты индивидуальные. Назначения канонизируются по действующим
объединениям; один сотрудник, связанный с обеими сторонами объединения,
учитывается один раз. Сотрудники с совпадающим ФИО остаются отдельными по ID.
Если действующих директоров нет, премия директоров 0 с явным примечанием.
Если директор есть, но его ставок нет, это **не** нулевая премия — результат
директоров не определён. Нулевой/отрицательный план даёт пустой коэффициент.

## Сохранение и Excel

«Рассчитать и сохранить» создаёт IntegralPlan2026Calculation. Снимок содержит
две суммы и два коэффициента, детали премий директоров и основания по товарным
сочетаниям/O0–O4. Ставки и реальные суммы находятся только в базе портала и
пользовательской выгрузке, не в исходном коде. Изменения плана или коэффициентов
не изменяют старые результаты. Предыдущие расчёты доступны по отдельным URL.

Excel: «Интегральные 2026» (два коэффициента), «Директора» (расшифровка премий),
«Основание» (план/сегменты, премии политик, продаж и директоров, примечания).
Проценты записаны числовыми дробями, внешние названия — буквальным текстом.

Требуется миграция 0036. Расчёт выполняется по загруженному плану в базе портала,
без SQL Agent, пересчёта факта 2025/2026 и изменения действующих коэффициентов.
Рассчитывать могут администратор, моделятор, финансист и генеральный директор;
наблюдатель только просматривает/выгружает. Личные роли не получают доступ
ко всему плану компании через этот отчёт.
