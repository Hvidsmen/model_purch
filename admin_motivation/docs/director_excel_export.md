# Выгрузка коэффициентов всех директоров в Excel

Кнопка **«Excel — все директора»** находится в **Мотивация → Глобальные коэффициенты**, в блоке действий «Директора». Сначала выберите нужную версию коэффициентов. Выгрузка не ограничивается текущим филиалом, сотрудником или поиском товарной матрицы.

В файле один лист «Директора»: №, директор, подразделение, группа планов продаж, группа ERP, марка/бренд, K0–K4 и настройки формулы. Строка 1 содержит выбранную версию, статус и ревизию. Двухуровневые заголовки, автофильтры, закрепление классификации и процентный формат соответствуют образцу. Например, сохранённое значение 0.0016 отображается как 0.16%, оставаясь числом с исходной точностью.

Источник — все сохранённые `SubdivisionDirectorCoeff` выбранной версии. Глобальные директорские шаблоны `GlobalDirectorCoeff`, у которых нет конкретного сотрудника и подразделения, не подмешиваются к персональным строкам. Исторически сохранённые строки архивированных сотрудников и подразделений не удаляются из выгрузки. Отсутствующие коэффициенты не заменяются глобальными и не дополняются вымышленными нулями; если строк нет, файл содержит явное сообщение.

Настройка формулы совпадает с действующей SQL-выгрузкой мотивации: явная формула строки → формула по умолчанию выбранной версии → прежнее правило по группе товара (`director_variation`). Имена и классификация записываются как буквальный текст Excel, коэффициенты — как числа. Если версия изменилась за время формирования файла, скачивание отменяется с предложением повторить, чтобы не выдавать смешанную ревизию.

Выгрузка выполняется через GET существующей страницы глобальных коэффициентов (`export=directors_xlsx&version=...`) и не меняет настройки или данные DWH. Доступ ограничен ролями, которым разрешён общий просмотр глобальных настроек. Миграции и новые зависимости не нужны.
