Копирование параметров товаров

Скопирует параметры только тех товаров, которые уже есть в «{{ current_scenario.name }}» и совпадают по плановой группе. Новые товары из источника не добавляются; состав текущего сценария сохраняется.
Совпадающие строки получат EXW, объёмы, пошлину, поставщика, запас и сохранённые показатели источника. DDP пересчитается по настройкам текущего сценария. После копирования обновите план, факт и сток за период текущего сценария.
