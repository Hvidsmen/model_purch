Для групп, отсутствующих в плане за этот период, DDP и объём берутся из текущих остатков. При нескольких значениях объёма в группе рассчитывается среднее с весом по количеству остатков.

DDP за единицу = сумма DDP / количество. Объём за единицу = общий объём / количество. Загружаются только группы с положительным количеством. Сопоставление — по полю «План. группа»; значения одинаковы для всех товаров группы.

Обновляются отдельные плановые поля. Расчётный DDP и введённый объём товара сохраняются. Прежние плановые значения заменяются; у групп без совпадения плановые поля очищаются.
