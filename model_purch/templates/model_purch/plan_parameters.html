Параметры товаров из плана продаж

{{ current_scenario }} · Период загрузки: {{ current_scenario.date_start_plan|date:'d.m.Y' }} — {{ current_scenario.date_end_plan|date:'d.m.Y' }}

Для групп без плана за этот период DDP и объём берутся из остатков на дату начала сценария. Факт DDP и объём — по продажам за год начала сценария и два предыдущих года. Средневзвешенный DDP = (расчётный DDP × (количество плана − количество стока) + DDP стока × количество стока) / количество плана. Без количества плана значение не рассчитывается.

DDP за единицу = сумма DDP / количество. Объём за единицу = общий объём / количество. Загружаются только группы с положительным количеством. Сопоставление — по полю «План. группа»; значения одинаковы для всех товаров группы.

Обновляются отдельные плановые поля, факт и данные стока. Расчётный DDP и введённый объём товара сохраняются. Прежние плановые значения заменяются; у групп без совпадения загруженные поля очищаются.
