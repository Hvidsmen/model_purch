Правила импорта:
  • Файл должен быть строго в формате .xlsx
  • Первая строка — заголовки колонок (как в экспорте)
  • Дополнительные колонки — объём контейнера, м³ и пошлина, %. В старых файлах без неё сохраняется текущий объём; для новых товаров используется 65 м³. Пошлина без колонки сохраняется у существующего товара, а у нового равна 0%.
  • Если ID указан и существует в текущем сценарии — запись обновится
  • Если ID пустой или не найден — создастся новая запись
