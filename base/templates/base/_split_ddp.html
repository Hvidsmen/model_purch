Заполнить DDP

Выберите источник и группы. Можно сразу рассчитать и сохранить; предпросмотр необязателен. Надбавка к себестоимости задаётся отдельно от наценки продаж.

Остатки на {{ scenario.stock_date|date:'d.m.Y' }} включительно. Только склады с назначением «Продажа», без хранения и товара в пути. DDP блока = суммарная себестоимость в USD / остаток в штуках. DDP комплекта = внутренний + наружный блок; группа взвешивается по долям мощностей. При неизвестной стоимости или неположительном остатке DDP не подставляется.

Берётся итоговый DDP с доставкой, пошлинами и прочими расходами. Сопоставьте каждую мощность с группой закупок либо выберите DDP всей группы без детализации. Поиск доступен в поле выбора.

DDP по мощностям взвешивается по сохранённым долям плана. При применении предложения по мощностям обновятся соотношения их DDP; модели и доля стоимости внутреннего блока заполняются по факту. Для DDP всей группы соотношения сохранятся.

Режим действует только на выбранные группы. При дозаполнении положительный DDP сохраняется. «Рассчитать и сохранить» сохранит также текущие изменения таблицы продаж. Вставка не сохраняет сценарий. После проверки нажмите «Сохранить изменения» или Ctrl+S. Нет данных — поле останется без изменений.
