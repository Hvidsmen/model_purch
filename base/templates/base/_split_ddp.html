Заполнить DDP

Сначала выберите источник и группы, затем проверьте предложение. Надбавка к себестоимости задаётся отдельно от наценки продаж.

Берётся итоговый DDP с доставкой, пошлинами и прочими расходами. Сопоставьте каждую мощность с группой закупок либо выберите DDP всей группы без детализации. Поиск доступен в поле выбора.

DDP по мощностям взвешивается по сохранённым долям плана. При применении предложения по мощностям обновятся соотношения их DDP; модели и доля стоимости внутреннего блока заполняются по факту. Для DDP всей группы соотношения сохранятся.

Вставка не сохраняет сценарий. После проверки нажмите «Сохранить изменения» или Ctrl+S. Нет данных — поле останется без изменений.
