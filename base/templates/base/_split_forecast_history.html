Прогноз продаж до начала плана

Период: после среза {{ scenario.stock_date|date:'d.m.Y' }} до начала плана {{ scenario.start|date:'d.m.Y' }}. Если выбран год среза стока, берём неполный год с 1 января до даты среза (не позднее сегодняшнего дня) и считаем средние дневные продажи × число дней прогноза. Для предыдущих лет берём те же календарные даты. Используются только каналы этого сценария. Если дата 29 февраля отсутствует, используется 28 февраля.

По каждой мощности: минимум чистых продаж внутренних и наружных блоков × (1 + корректировка / 100). Возвраты уменьшают продажи. Отсутствие истории не заменяется нулём. После применения прогноз сохраняется по мощностям.

Выполнение группы = факт / план за одинаковый прошедший период. Прогноз = план на оставшийся период после среза до начала сценария × выполнение. Используется выбранная версия регистра планов продаж и каналы сценария. Неполные месяцы плана распределяются по рабочим дням. Выполнение выше 100% допускается. Прогноз ограничен остатком на срез + поступлениями до начала плана отдельно по мощности и каждому блоку; отрицательный начальный запас из-за прогноза не создаётся.

Факт и прошедший план — по {{ scenario.stock_date|date:'d.m.Y' }} включительно. Оставшийся план берётся с дня после среза до начала сценария.

«Рассчитать и сохранить» сразу сохраняет рассчитанные группы. Группы с ошибками пропускаются; их список и причины будут показаны после операции. Предпросмотр необязателен.
