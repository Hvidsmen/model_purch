# Временный тест основного расчёта за все кварталы

По умолчанию включены I–IV кварталы и год. Годовые суммы и условия IV квартала
сохраняют прежние правила; повторные доплаты за кварталы не включаются.
После обновления сохраните параметры/расписание основного задания в Центре
расчётов и запустите расчёт заново. Просто обновить страницу недостаточно:
старое SQL-задание и сохранённые результаты не содержат новых кварталов.

## Быстрый возврат

В корне проекта создайте `.local/motivation-main-periods.json`:

    {"all_quarters": false}

Перезапустите портал, сохраните параметры/расписание основного задания заново
и выполните основной расчёт. Он снова выдаст только IV квартал и год;
обычные фильтры вернутся к этим периодам. Отдельный дополнительный сценарий
всех кварталов останется доступен как прежде. Удалять код/данные не требуется.
Для повторного включения измените false на true и повторите те же действия.

Файл настроек не попадает в Git. Уже зафиксированные распределения и ссылки
на их версии не удаляются и не меняются при переключении. До нового расчёта
отчёт показывает предупреждение о несовпадении сохранённых периодов с режимом.
