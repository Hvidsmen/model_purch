# Отдельные справочники модели планирования продаж

Раздел «Справочники» содержит ссылки на две самостоятельные страницы:

- `/sales-planning/directories/channels/` — каналы продаж: поиск по названию
  и фильтр «Активные / Неактивные / Все».
- `/sales-planning/directories/goods/` — номенклатура: поиск по наименованию,
  коду и классификации, активность, группа планирования, группа планов продаж,
  марка, мощность, тип блока, INV / On-Off и производитель / завод.

Фильтры применяются совместно. На странице выводится до 50 записей;
переход по страницам сохраняет поиск и фильтры. «Сбросить» возвращает список
активных записей. Номенклатура во всех режимах ограничена товарной группой
«Бытовые кондиционеры». Неактивные записи видны только при выборе
соответствующего фильтра.

У каждого справочника своя кнопка обновления из DataWH. Просмотр,
поиск и фильтрация читают только локальные данные. Обновление выполняется
администратором через POST с CSRF-защитой, затрагивает только выбранный
справочник и сохраняет текущие фильтры, возвращая на первую страницу.
При ошибке выводится сообщение без деталей подключения.

Старый адрес `/sales-planning/directories/` открывает страницу выбора
справочника. Старые POST-действия обновления на этом адресе продолжают
работать и после успеха перенаправляют на страницу нужного справочника.
