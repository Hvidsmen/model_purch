# Раскрытие плана продаж по мощностям

На вкладке «План продаж» нажатие на название группы раскрывает рассчитанные
строки мощностей. Повторное нажатие скрывает их. Управление работает мышью,
Enter и пробелом, в том числе в утверждённом сценарии. Раскрытие не сохраняет
форму и не меняет ревизию.

Для каждой мощности показываются комплекты, наценка и выручка по каналам,
а также общий итог. Значения собираются из фактического распределения плана
по месяцам и мощностям, включая его округления. Количество учитывается по
одному типу блока; стоимость и выручка включают оба. Если распределение не
рассчитано, выводится «—». Исторический факт сохранён только по группе и
не распределяется между мощностями искусственно.

Перед группой добавлены справочные колонки из номенклатуры:

| Колонка | Поле DataWH.erp.[Справочники.Номенклатура] |
| --- | --- |
| Группа планов продаж | Даичи_ГруппаПлановПродаж |
| Марка | Марка |
| Тип наружного блока | БИТ_ТипНаружногоБлока |
| Завод | Производитель |

Если у группы несколько значений, перечисляются все уникальные значения.
Отсутствующие значения показываются прочерком. Завод не извлекается из
названия группы.

При обновлении портала требуется применить миграцию
`0011_salesplanninggoods_manufacturer`. Затем на странице справочников
модели планирования продаж нужно обновить номенклатуру из DataWH:
это заполнит новое поле производителя. Старые сценарии получают справочные
значения по номенклатуре, уже входящей в их снимок, без пересоздания сценария.
Новые снимки сохраняют справочные значения при создании или обновлении состава.
