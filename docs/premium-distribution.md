# Распределение премий при закрытии периода

Отдельное меню «Распределение премий» доступно администратору, генеральному
директору, директору подразделения и финансисту. Финансист читает отчёты и
выгружает завершённые версии; директор редактирует только свои подразделения.

Перед созданием ответственный корректирует генеральские коэффициенты периода
в существующем редакторе и запускает расчёт. Затем выбираются завершённый расчёт,
подразделение, закрытый период и валюта. После проверки актуальности DWH-таблиц
под общей блокировкой сохраняется снимок исходных сумм, параметров и версий
коэффициентов. Изменение текущих таблиц результатов не меняет этот снимок.
Основной расчёт доступен для IV квартала/года; для I–III нужен завершённый
расчёт всех кварталов. Сценарий для акционеров не является источником выплат.

Квартал: отдельные фонды продаж и политиков. Год: отдельные фонды годовых
премий и доплат для каждого из двух видов мотивации. Суммы по людям округляются
до центов, фонд равен их сумме. Валюта выбирается одна на подразделение/период:
второе распределение в другой валюте не позволяет повторить те же выплаты.
Уже распределённые квартальные премии в годовые фонды не включаются.

Директор сохраняет изменения, при необходимости добавляет строку сотрудника
с нулевой исходной суммой, затем завершает распределение. Остатки всех фондов
должны быть равны нулю; ненулевые суммы без сотрудника запрещены; изменения
политиков требуют комментария. Отдельного согласования нет. Завершение
фиксирует новую версию и закрывает редактирование.

Excel, ссылка и кнопка подготовки письма доступны для завершённой версии.
Письмо открывается в почтовом клиенте: пользователь указывает получателей и
прикрепляет Excel самостоятельно. Автоматическая рассылка не выполняется.
Ссылка требует входа и проверки доступа к подразделению.

Администратор или генеральный директор может открыть распределение повторно
с обязательной причиной. Предыдущая завершённая версия и её Excel доступны
в истории по прежним ссылкам `?version=N`. Каждое сохранение сопровождается
снимком и автором; устаревшая ревизия формы не перезаписывает новые изменения.
Эти суммы являются распределением премий, а не регистрацией банковской выплаты.

Установка: применить миграцию `0049_premium_distribution`, перезапустить портал.

## Справочник продаж и третья сумма

Директор добавляет и редактирует сотрудников только своего подразделения через
«Сотрудники продаж». Связь с учётной записью задаёт администратор. Сотрудник с
датами работы в закрываемом периоде доступен для исторического распределения,
в том числе после увольнения. Использованные ФИО/подразделение не меняются:
это сохраняет связь с историей. Архивирование и уточнение дат доступны.

Добавление получателя в распределении выполняется выбором из справочника.
После завершения отчёты показывают третью сумму «После распределения»;
нулевой расчётный вклад не скрывает назначенную человеку премию. Годовая
премия и доплата сохраняются раздельно. Черновик не подставляется вместо
итога; повторное открытие скрывает неподтверждённую новую версию, старые
завершённые версии доступны по ссылкам из истории.

Завершённое распределение привязано к году, подразделению, периоду и валюте
и сохраняется при последующих пересчётах. В детальном отчёте есть ссылка на
его зафиксированную версию. По товарным фильтрам суммы не разбиваются и не
подставляются в товарные строки. В Excel добавлен лист с возможной,
расчётной и распределённой премией, отдельной доплатой и версией.
Миграции: 0049 и 0050.
