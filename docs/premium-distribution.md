# Распределение премий при закрытии периода

Отдельное меню «Распределение премий» доступно администратору, генеральному
директору, директору подразделения и финансисту. Финансист читает отчёты и
выгружает завершённые версии; директор редактирует только свои подразделения.

Перед созданием ответственный корректирует генеральские коэффициенты периода
в существующем редакторе и запускает расчёт. Затем выбираются завершённый расчёт,
подразделение, закрытый период и валюта. После проверки актуальности DWH-таблиц
под общей блокировкой сохраняется снимок исходных сумм, параметров и версий
коэффициентов. Изменение текущих таблиц результатов не меняет этот снимок.
Основной расчёт доступен для IV квартала/года; для I–III нужен завершённый
расчёт всех кварталов. Сценарий для акционеров не является источником выплат.

Квартал: отдельные фонды продаж и политиков. Год: отдельные фонды годовых
премий и доплат для каждого из двух видов мотивации. Суммы по людям округляются
до центов, фонд равен их сумме. Валюта выбирается одна на подразделение/период:
второе распределение в другой валюте не позволяет повторить те же выплаты.
Уже распределённые квартальные премии в годовые фонды не включаются.

Директор сохраняет изменения, при необходимости добавляет строку сотрудника
с нулевой исходной суммой, затем завершает распределение. Остатки всех фондов
должны быть равны нулю; ненулевые суммы без сотрудника запрещены; изменения
политиков допускают необязательный комментарий. Отдельного согласования нет. Завершение
фиксирует новую версию и закрывает редактирование.

Excel, ссылка и кнопка подготовки письма доступны для завершённой версии.
Письмо открывается в почтовом клиенте: пользователь указывает получателей и
прикрепляет Excel самостоятельно. Автоматическая рассылка не выполняется.
Ссылка требует входа и проверки доступа к подразделению.

Администратор или генеральный директор может открыть распределение повторно
с обязательной причиной. Предыдущая завершённая версия и её Excel доступны
в истории по прежним ссылкам `?version=N`. Каждое сохранение сопровождается
снимком и автором; устаревшая ревизия формы не перезаписывает новые изменения.
Эти суммы являются распределением премий, а не регистрацией банковской выплаты.

Установка: применить миграцию `0049_premium_distribution`, перезапустить портал.

## Справочник продаж и третья сумма

Директор добавляет и редактирует сотрудников только своего подразделения через
«Сотрудники продаж». Связь с учётной записью задаёт администратор. Сотрудник с
датами работы в закрываемом периоде доступен для исторического распределения,
в том числе после увольнения. Использованные ФИО/подразделение не меняются:
это сохраняет связь с историей. Архивирование и уточнение дат доступны.

Добавление получателя в распределении выполняется выбором из справочника.
После завершения отчёты показывают третью сумму «После распределения»;
нулевой расчётный вклад не скрывает назначенную человеку премию. Годовая
премия и доплата сохраняются раздельно. Черновик не подставляется вместо
итога; повторное открытие скрывает неподтверждённую новую версию, старые
завершённые версии доступны по ссылкам из истории.

Завершённое распределение привязано к году, подразделению, периоду и валюте
и сохраняется при последующих пересчётах. В детальном отчёте есть ссылка на
его зафиксированную версию. По товарным фильтрам суммы не разбиваются и не
подставляются в товарные строки. В Excel добавлен лист с возможной,
расчётной и распределённой премией, отдельной доплатой и версией.
Миграции: 0049 и 0050.

## Детальные коэффициенты гендиректора

В таблице подразделений ссылка «Детальные коэффициенты» открывает окно поверх
реестра для выбранного подразделения, года и периода. Можно задать коэффициент
продаж, политиков и директоров; для политиков и директоров — персональные
исключения по точному ФИО из расчёта. Приоритет: персональный коэффициент,
коэффициент вида мотивации, общий коэффициент подразделения. Значения не
перемножаются. Пустое значение вида наследует общее; ноль является заданным
значением. Массовое подтверждение общего множителя сохраняет детальные настройки.

Гендиректор и администратор видят сравнение «К выплате без коэффициентов» /
«После корректировок», изменение суммы и процента, эффективный коэффициент
(сумма после / сумма до). Это премии после проверки условий выплаты, до
распределения директором. В сравнении участвуют продажи, политики и директора;
годовая премия и доплата за кварталы показаны раздельно. При нулевой исходной
сумме коэффициент и процент не определяются. Изменение полей обновляет
предварительный расчёт в окне, сохранение выполняется отдельной кнопкой.

Сравнение читает последний проверенный завершённый рабочий расчёт нужного года,
не акционерный сценарий. Три сгруппированных запроса загружают суммы всех
подразделений сразу; исходные суммы кешируются на 10 минут по запуску, периоду
и валюте, настройки применяются заново при каждом просмотре. Доступность и
актуальность результата проверяются также при чтении кеша. Ошибка источника не
заменяется нулевыми суммами. Старая схема с поправками внутри SQL требует нового
расчёта с единым коэффициентом. Сравнение последнего расчёта не изменяет ранее
зафиксированные фонды.

Сохранение доступно только администратору/гендиректору за закрытый период до
фиксации фондов. Ревизия защищает от устаревшей формы, история содержит все
общие, видовые и персональные значения. Снимок распределения сохраняет настройки.
Установка: применить миграцию `0055_closing_detailed_coefficients` и перезапустить
портал. Подтверждённые значения применяются в отчётах без повторного умножения;
перезапуск SQL не требуется для уже завершённого расчёта с единым коэффициентом.


## Общий остаток для продаж, политиков и директоров

Новые распределения сохраняют три вида мотивации: продажи, политики и директора.
Исходные суммы уже учитывают коэффициенты гендиректора. Между вкладками можно
свободно переключаться с сохранением текущих изменений. Уменьшение премии
освобождает общий остаток подразделения, который можно назначить человеку в
любом из трёх видов мотивации. Размеры исходных фондов и суммы `original` не
перезаписываются; новая разбивка по видам определяется назначениями.

Каждый тип выплаты имеет независимый бюджет: квартальная премия, годовая премия,
доплата за кварталы. Из одного бюджета нельзя покрывать другой. Сохранение и
переход запрещены при отрицательном остатке. Завершение из любой вкладки возможно
только при нулевом остатке всех выплат и отсутствии неназначенных сумм.

Для каждого политика и директора минимальная сумма равна 75% исходной премии,
округлённым вверх до копейки. Проверка выполняется по человеку, виду мотивации
и типу выплаты, по исходным суммам снимка, а не по предыдущему сохранению.
Повторное сохранение, переход по вкладкам и повторное открытие лимит не обнуляют.
Новые получатели с нулевой базой имеют нулевой минимум. Неназначенные исходные
суммы можно распределить полностью. Отрицательные исходные начисления сохраняются
без редактирования; они не превращаются в положительную премию через ползунок.

На всех вкладках показан общий остаток по каждой выплате; таблица показывает
исходную сумму, минимум, текущую премию и процент уменьшения. Ползунок и ручной
ввод проверяют бюджет; сервер независимо проверяет лимиты, права подразделения
и ревизию. Продажников можно добавлять из справочника своего подразделения или
создавать; директоров — только из действующего справочника своего подразделения.

Завершённое распределение применяется в отчётах также к директорам. Excel
содержит исходные фонды, назначения и отдельный лист «Общий остаток». Завершённые
версии и их снимки не изменяются при обновлении кода.

Старые черновики не переводятся автоматически: в них доступна кнопка «Обновить
черновик». Она сохраняет назначения и исходные суммы, добавляет директоров из
того же подтверждённого расчёта и включает новые правила. Если расчёт уже заменён
или старые назначения нарушают минимум 75%, переход отменяется с пояснением.
Старое распределение без этапов сначала переводится в этапы существующим действием.
Миграция базы и переустановка SQL для новой логики не требуются.
