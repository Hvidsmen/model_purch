# Иерархия и подытоги плана продаж

Таблица плана продаж сгруппирована по уровням:

`группа планов продаж → марка → тип наружного блока → завод → группа планирования → мощность`.

Каждый справочный уровень имеет строку подытога по каналам и всем каналам:
количество, выручка и наценка плана, годовой и помесячный исторический факт,
начальный сток и его составляющие, запланированные и новые поставки,
конечный сток. DDP не суммируется: это стоимость единицы, а не аддитивный итог.

Количество и суммы складываются по уникальным входящим группам. Наценка
подытога равна общей выручке, делённой на общую себестоимость; среднее
арифметическое наценок не применяется. Неизвестные значения не заменяются
нулями. Остатки берутся из существующего расчёта по мощностям, затем
суммируются по группам.

Если у группы несколько значений справочного признака, их сохранённая
комбинация становится одним разделом: группа не дублируется в нескольких
ветках. Пустые значения попадают в раздел «Не указано».

Нажатие на строку подытога сворачивает или раскрывает её ветку. Кнопки
«Свернуть разделы» и «Развернуть разделы» управляют всей иерархией.
Состояние разделов сохраняется в sessionStorage для текущего сценария,
включая переход после сохранения. Эта настройка не записывается в сценарий.
Мощности по-прежнему раскрываются вручную; сохранение плана не раскрывает их.

Подытоги доступны для просмотра. Редактируются исходные строки групп;
свёрнутые строки остаются в форме, поэтому сохранение не теряет их значения.
Общий итог внизу считается по исходным группам, а не повторным сложением
всех уровней. Управление поддерживает клавиатуру и утверждённые сценарии.
Миграция БД и новая загрузка SQL не требуются.
