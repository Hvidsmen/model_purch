# Компактная карточка группы планирования

Карточка разделена на сворачиваемые разделы: примечание, связанные группы,
замещающие группы, мощности и пары блоков, состав номенклатуры.
Мощности также раскрываются отдельно. Ошибки автоматически раскрывают
нужный раздел. При переходе по страницам состава список моделей остаётся открытым.

В связанных и замещающих группах кнопка «Добавить» открывает окно выбора.
Доступны поиск по названию и фильтры по марке, группе планов продаж,
INV / On-Off и производителю. Группы выбираются флажками; «Выбрать найденные»
добавляет все результаты текущего фильтра. Выбор за пределами текущего
фильтра сохраняется. «Снять выбор в списке» снимает только найденные группы.

«Добавить выбранные» переносит выбор в текущую форму, но не записывает его
на сервер. «Отмена» или Escape закрывают окно без изменения формы.
Выбранные группы показаны компактным списком; крестик убирает одну связь.
Для записи примечания и обеих категорий связей нужно нажать
«Сохранить настройки».

Состав допустимых групп и проверка прав остаются серверными. Нельзя
выбрать текущую группу в качестве собственной связи. Сохранённые неактивные
связи не теряются. Без JavaScript доступны прежние стандартные поля
множественного выбора. Работа с парами блоков и обновление справочников
не изменены; дополнительная миграция не требуется.
