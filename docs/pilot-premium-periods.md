# Пилот: премия за 4-й квартал и годовая премия

С 27 октября 2026 в портале доступны только два периода премии:

- 4-й квартал — существующая формула нарастающим итогом за 1–4 кварталы;
- год — отдельная годовая премия.

Это не фильтр сделок за октябрь–декабрь. План и факт всего года остаются входными данными обеих формул. Сравнение плановых премий использует ту же нарастающую базу: при выборе Q4 квартальная доля применяется ко всему годовому плану, при выборе года добавляется годовая доля. Общая сумма — выбранные премии; годовая премия сама по себе не включает квартальную.

## Расчёт и отчёты

`pilot_calculation.patch` изменяет только копию `motivation.PortalCalcBySub`. В распознанных выходных ветках Q1–Q3 входные выборки пустые; Q4 и год сохраняют прежнюю базу и формулы. Первое пустое SELECT INTO сохраняет схему результирующей таблицы. INSERT годовой доплаты не выполняется. Поправки подразделения применяются до отключённого INSERT. Исходная `sp_CalcBySub` не меняется. При неизвестной структуре процедура не подменяется и расчёт не запускается.

Все роли видят только Q4 и год в старых и новых отчётах премий и их выгрузках. Подбор сотрудников/товаров выполняется в этой же области. Отчёт исходных сделок не ограничивается двумя квартальными периодами: это фактические данные, а не реестр начисленных квартальных премий. Низкоуровневые построители таблиц сохраняют возможность разбирать исторические данные; ограничение применяется в точках загрузки отчётов.

В параметрах новых запусков сохраняются `premium_periods=["4","5"]` и `quarter_catchup=false`. Старые запуски не объявляются расчётом по текущей политике. Сохранённая история не переписывается.

## Применение

После обновления запустите расчёт вручную из центра расчётов: портал подготовит процедуру, сохранит параметры и запустит задание. Для автоматического запуска сначала сохраните параметры и расписание задания. Простое обновление страницы не запускает и не изменяет расчёт DWH. Проверки кода используют фикстуры и локальные тестовые базы; корпоративный SQL Server из среды разработки недоступен.
