# Модели и стоимость при выборе «Из факта»

На вкладке распределения мощностей кнопка «Из факта» предлагает не только
доли количеств, но и заполнение пустых моделей и параметров стоимости.
Предложение применяется к форме; для записи нужно нажать «Сохранить изменения».
Уже заполненные значения в снимке или текущей форме не заменяются.

Для каждого типа блока выбирается первый однозначный вариант:

1. Сохранённая корректная пара из справочника группы, входящая в снимок.
2. Единственная активная модель нужной группы, мощности и типа блока.
3. Модель с единственным максимальным положительным объёмом фактических
   продаж среди допустимых кандидатов. При равенстве лидеров выбор остаётся пустым.

Неактивные модели, модели другой группы или мощности автоматически не выбираются.
Если пользователь уже выбрал модель, она не заменяется.

Стоимость читается отдельно из `DataWH.dbo.Sales` только для целевой группы:
та же база `AmountExwAEUSD`, что используется в историческом факте портала.
Период совпадает с распределением: пять предыдущих календарных лет,
с отсечением по последнему завершённому месяцу на дату стока.

Для каждой выбранной модели средняя стоимость единицы равна
`SUM(AmountExwAEUSD) / SUM(Quantity)`. Сохраняются знаки возвратов;
нужны положительные итоговые количество и стоимость и отсутствие пропусков.

- Стоимость комплекта мощности — сумма средних стоимостей выбранных блоков.
- Соотношение DDP — стоимость комплекта мощности, делённая на минимальную
  стоимость среди активных мощностей с полной стоимостной базой.
- Доля стоимости внутреннего блока — его средняя стоимость, делённая
  на стоимость комплекта, умноженная на 100%.

Параметры округляются до шести знаков. Стоимость из более широкой группы
или другого бренда не подставляется, даже если доли количеств получены
по расширенному правилу распределения. При недостатке данных выводится
пояснение; количества и однозначные модели остаются доступны, стоимость
можно заполнить вручную.

Предложенные параметры подписываются вместе с ревизией и долями.
При сохранении повторное чтение источника не требуется. Утверждённые
сценарии и устаревшие ревизии защищены прежними проверками.

Для ранее рассчитанных долей с пустыми параметрами после обновления портала
нужно повторно нажать «Из факта», проверить предложение и сохранить.
Миграция базы данных не требуется.
