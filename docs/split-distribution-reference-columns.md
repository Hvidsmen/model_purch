# Справочные колонки в распределении

В таблицах «Месяцы» и «Мощности и модели» перед группой планирования
выводятся группа планов продаж, марка, тип наружного блока и завод.
Используется тот же источник справочных значений, что на вкладке плана:
сохранённые признаки снимка и локальная номенклатура для прежних снимков.
Завод соответствует полю «Производитель», а не части названия группы.

При нескольких значениях перечисляются все сохранённые значения.
Отсутствующее значение отображается прочерком. Колонки доступны только
для просмотра и повторяются для каждого канала в помесячном распределении.

Справочные колонки не входят в месячные значения и блок вставки из Excel.
Идентификаторы групп, каналов, месяцев и мощностей не меняются.
При открытии страницы дополнительных запросов в DataWH нет.

На широком экране таблица прокручивается горизонтально, сохраняя ширину
полей распределения. На узком экране справочные признаки имеют собственные
подписи в карточке строки. Миграция и новая загрузка данных не требуются.

Те же четыре справочные колонки показаны на вкладке «Сток и закупки»
перед группой планирования. В строках мощностей оставлены пустые ячейки:
справочные признаки относятся к родительской группе. При раскрытии блоков
и каналов ширина служебных строк учитывает новые колонки. Поля остатков,
прогноза, плана и новых поставок сохраняются как прежде.

В плане продаж, распределении по месяцам/мощностям и стоке доступны
совместные фильтры по четырём справочным колонкам. Выбор хранится в сессии
браузера отдельно для сценария и сохраняется между вкладками и сохранениями.
Фильтрация скрывает строки, не отключая поля форм; скрытые значения входят
в обычное сохранение. Подытоги и общие итоги остаются по всему сценарию,
что явно указано под фильтрами. Кнопка сброса возвращает все группы.

### Массовое распределение

В распределении по месяцам и мощностям черновика доступны флажки строк,
«Выбрать все показанные», «Снять выбор» и выбор способа «Из факта»,
«Равномерно», «Вручную». Кнопка «Применить к выбранным» учитывает текущие
фильтры, включая справочные: скрытые выбранные строки не меняются.
Ручной способ открывает ввод, сохраняя текущие значения. Факт загружается
последовательно через обычные подписанные предпросмотры, ошибки остаются
в соответствующих строках. Сохранение всех изменений выполняется отдельно
существующей кнопкой, с прежней проверкой сумм и ревизии сценария.

### Два вида таблицы

В плане продаж, распределении по месяцам/мощностям и стоке доступны
«Таблица» и «Вложенный вид». Выбор сохраняется для сценария в текущей
сессии браузера и применяется при переходе между вкладками. Переключение
не отправляет форму и не создаёт копий редактируемых полей.

Во вложенном виде группы расположены по иерархии: группа планов продаж →
марка → тип наружного блока → завод → группа планирования. В плане продаж
сохраняются рассчитанные подытоги; в распределении и стоке заголовки
разделов показывают число групп. Доли разных групп и каналов не суммируются.
Разделы можно свернуть/развернуть. Плоский вид скрывает разделы и показывает
строки групп, сохраняя отдельное раскрытие мощностей и блоков. Массовый
выбор и вставка из Excel учитывают только показанные строки.

### Поиск и множественный выбор

Все четыре справочных фильтра содержат поиск и флажки нескольких значений.
«Выбрать найденные» добавляет результаты текущего поиска к выбору;
«Снять выбор» очищает этот фильтр, общий сброс очищает все четыре.
Пустой выбор означает все значения. Внутри одного фильтра работает ИЛИ,
между фильтрами — И. Поиск не снимает выбранные скрытые значения.
Составные значения из справочных колонок разделяются по запятой, поэтому
завод или марка выбираются отдельно, а не только целой комбинацией.

Выбор хранится массивами в sessionStorage сценария. Старый одиночный выбор
преобразуется автоматически. Раскрытие закрывается по Escape или нажатию
снаружи. Значения вставляются как текст, без HTML. Основной native multiple
select остаётся источником состояния, скрытым после создания интерфейса.
